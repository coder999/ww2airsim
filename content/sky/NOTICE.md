# Cloud noise volumes

`shape.bin.gz` (128³ RGBA8), `detail.bin.gz` (64³ RGBA8; RGB used), and
`curl.bin.gz` (128² RG8) are generated by
`npm run sky:build` (`tools/sky/noise.ts`) from mulberry32 with fixed seeds,
after Schneider & Vos, "The Real-Time Volumetric Cloudscapes of Horizon: Zero
Dawn" (SIGGRAPH 2015) -- method only, no data from that or any other source.
The packed shape channels contain Perlin-Worley plus three Worley octaves;
the packed detail channels contain three finer Worley octaves. The curl map
is the signed derivative of a tileable two-octave Perlin potential and
distorts detail coordinates without moving cloud bodies. Original,
AGPL-3.0-or-later. `tests/tools/skyNoise.test.ts` pins their
SHA-256; a rebuild that changes a byte changes that test in the same commit.

`weather.bin.gz` (512² RGBA8) is the cumulus weather map of Cloud Fidelity
II §3.3 (`tools/sky/weather.ts`): one Worley cell per cloud, with coverage
potential, cloud type and top height. It replaced Plan 16d's 64² coverage
field. Built the same way and under the same license by the same
`npm run sky:build` command.
