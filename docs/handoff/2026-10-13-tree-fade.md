## Change and limits

The rejected canopy trial's short range, dark colors and smooth crown normals
are removed. Both comparison modes use the original ground, tree geometry,
colors, normals, placement and range. High fades over approximately
0.87–1.15 miles. The procedural canopy is opt-in with `canopy=on` and mountain
horizon lighting remains off by default.

Pixel dissolve replaces the per-instance alpha threshold with a screen-pixel
pattern plus a stable tree-site seed. Crowns gain coverage progressively
instead of switching on together. There is no frame-to-frame random jitter,
extra pass or derivative-based alpha hashing.

**The fade band has visible stipple. The distant forest boundary remains.**
This experiment adds no far-field tree representation. Still-image inspection
confirms partial crowns and matching near-tree art; it does not establish that
the transition looks better in flight. Mark's review is pending.

DEV defaults to `treeFade=pixel`; `treeFade=whole` is the baseline. Production
retains whole-tree fading. Both paths retain the conservative altitude cull,
skipping tree draws when every resident crown is vertically out of range.

## GPU measurements

Reference Ryzen GPU, exclusive `ryzen-budget` lock, 2560×1440, High, 100%
render scale, noon, clouds off. Three windows per trees-on/off state, each
with more than 100 samples. Shader order reversed in the ridge view and tree
visibility order alternated. No other test or CPU job overlapped the run;
the preflight GPU check found background video decoding but no unrelated 3D load.

Values below are medians of the three window statistics, in milliseconds.

| View | Original p50 | Pixel p50 | Original p95 | Pixel p95 |
| --- | ---: | ---: | ---: | ---: |
| Low, 1,000 ft | 3.499 | 3.468 | 3.513 | 3.491 |
| Ridge, 6,000 ft | 3.373 | 3.377 | 3.634 | 3.640 |
| High, 13,000 ft | 2.955 | 2.962 | 3.238 | 3.482 |

The low and ridge differences do not show a meaningful added GPU cost.
Both high-view modes submit zero tree instances, so their tail difference
cannot be attributed to executing the dissolve shader. Timing drift remains:
one original ridge window reached 5.317 ms p95. All 36 recorded windows
remained below the 8.33 ms p95 tripwire.

Trees-on minus trees-off median p50 is approximately 0.60 ms original versus
0.56 ms pixel in the low view, and 0.09 ms in both ridge variants. High-view
cost is approximately zero with the shared altitude cull. These are full-frame
deltas, not isolated shader timings or proof of a speedup.
