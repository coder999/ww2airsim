## How A2 works

- The cloud layer list was already uniforms, so `cloudField.setLayers` rewrites them and
  `cloudShadow.refresh` re-reads the deck. Nothing recompiles.
- The shadow lookup is now wired into lighting and fx whenever the shadow mode is not
  `off` (`shadow.capable`). A clear sky's lookup returns 1.
- The cloud pass is built whenever the cloud tier is not `off`, and is composited only
  while there is a deck. A/B on nexus, clear sky (`gunnery-range`, 1280×720): p50 3.73 ms
  against 3.71 ms before. Only 13-14 samples, so this is a sanity check, not a budget figure.
  It is also the reason a cloudless URL boot now pays the cloud-pass compile at boot.
- The sea state goes through the same ocean rebuild a tier change uses (`swapOcean`).
- New diagnostics: `clouds().composited` and `seaState()`.
- Test: `scenarioPicker.spec.ts` runs both directions (cloudy to clear, clear to cloudy
  with a sea-state change), with expectations read from the scenario JSON. It was seen red
  with the hook disabled: it flew the boot scenario's 10:00 and 12:00 suns.
