# O1 handoff: ordnance models (2026-09-26)

O1 replaces the box bomb and cylinder rocket with real store models, an AN-M65
1,000 lb bomb and a 5-inch HVAR. Both are generated by script from cited
dimensions (Mark's choice). They hang on the drawn Wildcat from the sim's own
mounts, fly in the game, and have their own category in the Hangar. The design
is §2, §7 and §8 of
[`2026-09-26-ordnance-and-effects-design.md`](../superpowers/specs/2026-09-26-ordnance-and-effects-design.md).
The plan is [`2026-09-26-o1-ordnance-models.md`](../superpowers/plans/2026-09-26-o1-ordnance-models.md).

This work is complete on branch **`worktree-o1-ordnance`**, and Mark had it
merged into `main` on 2026-09-26 (`bddbc02`). Commits `e9d0d84`..this handoff's sit on
`242c35e`. `main` was merged in at `dbe27ec`, so the branch already carries
E1, 7e and M0.

## What shipped

- **Two generated stores**, one draw call each:

  | Model | Triangles (budget) | Bytes (budget) | Sources |
  | --- | --- | --- | --- |
  | `content/ordnance/an-m65.glb` | 2,180 (4,000) | 125,172 (400,000) | header of `tools/models/generated/an-m65.ts` |
  | `content/ordnance/hvar.glb` | 840 (2,000) | 59,552 (400,000) | header of `tools/models/generated/hvar.ts` |

  Each header lists which figures are cited (OP 1664; NASM A19820116000 for
  the HVAR) and which are ESTIMATE. The figures are not restated here. Both
  files rebuild byte-identically on nexus and on ryzen: the
  `generatedModels.test.ts` identity block ran on both hosts.
- **A `generated` source kind in the model manifest.** `models:build` sends
  such entries to `tools/models/generated/registry.ts`. The Sketchfab path is
  pinned byte-identical (`TOY_SHA256_BEFORE_O1`).
- **Mounts measured on the drawn Wildcat wing** (`npm run models:mounts`,
  `tools/models/wingSection.ts`). Content now holds these offsets for both
  aircraft. Values are x, y and z, with the clearance drop:

  | Mount | Offset (m) | Drop (m) |
  | --- | --- | --- |
  | racks | 1.563, 1.281, ±2.6 | 0.089 |
  | rail 1 | 1.358, 1.313, ±3.6 | 0.076 |
  | rail 2 | 1.398, 1.353, ±4.3 | 0.077 |
  | rail 3 | 1.426, 1.399, ±5.0 | 0.077 |

  `tests/tools/models/wildcatMounts.test.ts` asserts content against the
  measurement. The sim releases from these points (Mark's ruling). The
  1,500 m level release moved from 1,060 to 1,061 ticks and from 2,066.5 m to
  2,069.6 m. The strike tests were re-recorded for it.
- **Stores hang as the models** (`src/render/scene/stores.ts`) and the **pools
  draw them in flight** (`src/render/ordnance.ts` `setStoreModels`). The rocket
  flame sits at the HVAR's aft end. The Zero hangs nothing, because its spec
  has no stores.
- **The Hangar's `ordnance` category**: library entries, catalog cards and a
  stand. `__hangar.storeMounts()` serves Tier 2.

## Found along the way

- **The in-flight spec raced its own screenshot.** The chase view's falling
  bomb crosses 100–200 px during one remote capture, so sampling and then
  capturing measured empty sky. The spec now waits 75 sim ticks, pauses,
  samples, and asserts that nothing moved across the capture. The plan's 0.3
  contrast floor assumed a broadside bomb. Seen tail-on, the bomb fills about
  a sixth of its bounding disc, so the floor is 0.08. Empty sea measures 0.000.
- **The bomb flew broadside before O1.** The old box was modeled along z, not
  the flight axis (`ordnance.ts`).
- **The Zero hung stores its spec does not have.**
- **`stores.ts` held a hand copy of the sim's offsets** that had drifted. It
  now reads the spec's mounts. This closes the H2 handoff's "stores in the
  wrong place" open item.
- **OP 1664 gives the AN-M65 as 965–990 lb.** Content's 1,000 lb is
  unchanged.
- **On `main`: restart does not heal structures.** After a Restart, the Dulag
  hangar reads 90 hp against the expected 120. This was measured the same way
  on `main`'s primary slot at `dff7228` (2/2 runs) and on this branch (2/2). It
  is not O1's.
