# L1 building-materials and L2 shore-effects handoff

**Status:** merged to `main` 2026-10-11; not deployed. Mark accepted the
building materials and shoreline work and rejected the costlier tree pass.

## What shipped in the branch

### L1: building materials

- Three pinned CC0 Poly Haven materials provide corrugated steel, timber and
  concrete. Each has a separate mipmapped KTX2 albedo and OpenGL normal map.
  The six payloads total 1,211,421 bytes.
- `tools/textures/buildScenery.ts` and
  `tools/textures/scenerySources.ts` are the deterministic source/build
  ledger. `content/textures/scenery.json` is validated before runtime use.
  Provenance, page URLs and authors are recorded in `ASSETS.md`.
- The new detail modulates the existing weathered colors. Airfield, town and
  destructible-building geometry, identity, batching and draw counts are
  unchanged. Missing or invalid scenery textures warn once and fall back to
  the former procedural materials without blocking boot.
- DEV `?sceneryTextures=off|on` provides the A/B; the production-bundle test
  proves the query control is stripped.

### Tree pass: rejected and reverted

- Mark rejected the first seven-cluster/four-branch silhouette because the
  woody geometry protruded through the canopy.
- A bounded follow-up shortened the trunk and kept complete branch geometry
  inside slightly fuller foliage clusters. Its capture removed the spikes.
- The corrected exact-old/new locked comparison at 2560×1440 measured
  3.350 ms p95 for the legacy three-lobe/single-trunk tree and 3.678 ms for
  the bounded tree: +0.328 ms, +9.8%. Mark's rule was to revert if it cost
  more, so the geometry and leaf/bark materials were removed. Placement,
  draws and every other vegetation behavior remain exactly as on incoming
  `main`.

### L2: breaking surf and shallow water

- The existing `ShoreSurf` ribbon and its one material/draw now render a
  shallow-water gradient, two shoreward breaker crests, broken foam and
  backwash. No geometry, ocean, DEM, collision or simulation value changed.
- `Beaches.update` receives simulation seconds, so Pause freezes the water
  phase. A pure CPU twin pins bounds, periodicity and direction.
- DEV `?shoreFx=off|on` restores the exact static path for A/B;
  `?shoreTime=<non-negative seconds>` fixes a deterministic capture phase.
  These controls are absent from production.
