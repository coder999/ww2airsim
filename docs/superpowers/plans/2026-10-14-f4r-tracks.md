# F4R: Sherman wear and running tracks

Date: 2026-10-14. Branch `f4r-tracks` (from `f4-night-site-assets`). Viewing checkpoints: final product only; run unattended.

## Findings first

- The **Type 97 Chi-Ha already runs** its tracks (V1, 2026-10-09): `rigChiHa` spins the hull's 72 wheel shells in a vertex shader and scrolls the separate `Track` mesh's texture by `treadUPerMeter`. Game (`main.ts` `handle.drive(pose.distanceM, ...)`) and Hangar both call `rig.drive`. Plan: verify it with a measured test and image pair, change nothing in the ingested glb (provenance untouched).
- The **M4 Sherman has no running gear animation** (`rigSherman.drive` is empty): its belt is one static loft inside the joined hull mesh, sharing the single skin atlas, so a texture scroll is impossible.

## Work

1. **Sherman track links** (`m4-sherman.py`): replace the animated part of the belt with discrete shoes (about 6 in pitch, both sides) in one new kept node `Tracks`; keep a thin static belt underneath so gaps never show. New part, existing node names, origins and dimensions unchanged.
2. **Rig** (`vehicleRig.ts`): `rigSherman` gains `drive`: link shoes slide one pitch per pitch travelled (each vertex blends toward its previous link's matching vertex; wraps seamlessly), and the hull's wheel shells spin (road wheels, idlers, rollers, sprocket) with the Chi-Ha's shader. Wheel bolt heads are separate shells, so `wheelShells` gets an opt-in `nest` pass that makes fragments on a wheel's outboard face turn with it. `parts: ['turrets', 'drive']` so the Hangar speed bench works.
3. **Wear and detail** (`m4-sherman.py`, `colors.ts`): weld beads, spare track blocks on the glacis, jerry cans, tarp roll, hull-side tools, engine-deck plates, a bent lamp guard; baked wear via markings (mud and dust on the lower hull and sponsons, scuffs and bare-metal chips, rust streaks, dent smudges). Real dents are texture only.
4. **Tests**: rig (links/shells/phase direction/wrap), geometry (links count, link-to-link regularity), existing model/budget/provenance/deterministic-rebuild suites; Hangar e2e step for Sherman speed.
5. **Images**: Hangar captures of both tanks at rest and after travel, reviewed by eye.
6. Handoff `docs/handoff/2026-10-14-f4r-tracks.md`; push the branch only.

Budget: both entries stay inside 20,000 triangles, 8 draws, 1 MB; the Sherman is at 10,136 triangles and 3 draws today.
