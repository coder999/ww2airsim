# M1e: Zuikaku (1944), the first Japanese carrier

**Goal:** add an IJN fleet carrier that matches Essex: Zuikaku as at Leyte, October 1944. Track M in `MASTER_PLAN.md`.

**Run:** worktree `m1e-zuikaku`, started **after M1d merges** so it reuses M1d's bake path for downloads. Merged to `main` at the end. Unattended.
**Viewing checkpoints:** the final product only. Captures go in the handoff.

## Rulings (Mark, 2026-10-09)

| # | Ruling |
| --- | --- |
| E1 | **Source:** KTKloss, "IJN Shoukaku – Model for 1/4000 printing". <br>- Sketchfab uid `208f8ceb4ac84ad08b439bdba9a20dc9`, CC BY 4.0. <br>- KTKloss is also the author of our Essex, Cleveland and Mogami. <br>- The candidate and its license sidecar are already in `content/models/candidates/shokaku-cv-ktkloss.glb`. <br>- Vet it and record it per `ASSETS.md` before promoting it. <br>- The sister ships share a hull, so the same model stands for Zuikaku. |
| E2 | **The ship is Zuikaku, 1944.** Paint her in the Leyte-era camouflage: a green-gray hull pattern and the camouflaged flight deck. ESTIMATE the colors, and source each one in the spec. |
| E3 | **Armament, chosen for balance against Essex (M1d D3), not history:** <br>- **Heavy AA:** 8 twin 12.7 cm Type 89 mounts, two pairs on each side, as the mesh's sponsons show. <br>- **Light AA:** 4 triple 25 mm Type 96 mounts in total, two on each side. <br>- The spec comment records the real 1944 fit: 20 triple 25 mm, 36 single 25 mm, and 8 × 28-round 12 cm rocket launchers (English Wikipedia, "Shōkaku-class aircraft carrier", citing Lengerer and Campbell). |
| E4 | **Detail:** the M1d treatment. The UV survey picks 1, 2 or 3. The model ships with no textures, so 2 (a fresh UV layout, then the bake) is expected. |

## Tasks

- [ ] 0. Wait until `m1d-download-detail` is merged. Then create the worktree `../ww2airsim-m1e` and link the model cache.
- [ ] 1. Promote the model:
  - vet it (`ASSETS.md`: authorship, license, attribution text);
  - write the entry `tools/models/entries/zuikaku-cv.json`, modeled on `essex-cv.json`;
  - fit it to 257.5 m (845 ft) overall, after checking the source frame with `models:inspect`.

  The budget is Essex's: 1.5 MB, 60k triangles, 8 draws. Raise it only if the paint needs it, and record why.
- [ ] 2. Write the ship spec `content/ships/zuikaku-cv.json`:
  - the IJN side;
  - armament per E3, with positions taken from the mesh's sponsons and tubs;
  - the flight deck and arresting gear, as Essex has them, so landings work.

  Carve or generate the 12.7 cm twin and 25 mm triple kits. Reuse the M1b 25 mm triple kit if it fits.
- [ ] 3. The E2 paint and the E4 bake.
- [ ] 4. Enroll Zuikaku in every place Essex is enrolled (`grep -rn essex-cv src tests tools content`): the Hangar list, ship tests, captures, and deck quals if carriers are enumerated there. See each one fail once.
- [ ] 5. Captures: close, side-close, deck, 1,500 ft and the groove, plus one frame with Essex and Zuikaku side by side at the same distance.
- [ ] 6. Docs:
  - `ASSETS.md` (with the attribution);
  - `docs/models.md` (if the pipeline changed);
  - `CONTEXT.md` (if a new term appears);
  - the handoff `docs/handoff/<date>-m1e-zuikaku.md`;
  - Track M in `MASTER_PLAN.md`.

  Then merge, run `npm run verify` on `main`, push, and email the handoff.

## Done means

- Zuikaku loads in the Hangar within budget, painted and armed per E3, with mounts that train and elevate.
- A player can land on her deck.
- The rebuild tests pass.
- The handoff shows her next to Essex.
