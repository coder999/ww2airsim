## Design

**One new file, `src/sim/ai/attack.ts`** (pure). `AttackKind` is `'dive-bomb' | 'torpedo' | 'level-bomb' | 'kamikaze'`. `IngressOrders` gains an optional `attack`; `PilotDecisionState` gains an optional `attack` (the phase machine, written only for an attack pilot, so every other pilot's state is the shape it is today). Scenario JSON: `pilot.ingress.attack: "dive-bomb"`. Absent: orbit.

Phases per kind, each a small controller on the existing flight controllers (`controlsForDesiredVelocity`, `controlsForLiftVector`):

- **dive-bomb:** `approach` (the route's destination leg, climbing to a dive entry height if needed) -> `dive` (roll in at the range that makes a 60 degree line; aim at the target with its motion led and a skill-scaled aim offset; release at the pilot's release height, late by a draw within his reaction time; only through open doors) -> `pullout` (lift vector up at the load budget until climbing) -> `egress` (climb away) -> `approach` again while a store is left, else `done` (hold the heading).
- **torpedo:** `approach` -> `descend` (a shallow glide to run height, 200 ft) -> `run` (lead pursuit of the intercept the torpedo's own run speed solves; speed held under the drop envelope; the drop is judged against the envelope before the pulse and released inside the run's range, past the arming run) -> `egress` (climb away) -> `done`.
- **level-bomb:** `approach` at the route altitude over the target, release by `predictImpact` against the target, pull away.
- **kamikaze:** a committed fast dive that ends in the target (last, if time allows).

**Opt-in guarantee.** Nothing runs unless `ingress.attack` is present. `pilotTick` branches on it before the existing ingress flight; the golden, determinism and mission tests do not construct it.

**Bounded runs.** The calibration harness (`tests/sim/ai/attackHarness.ts`, `tools/ai/attackSweep.ts`) builds a flat-sea world with the destination ship's AA stripped, N seeds, a bounded number of ticks.

## Rulings (conservative defaults; Mark rules later)

- **R1:** the order is `pilot.ingress.attack`, explicit per raider, not inferred from the loadout. An author names the intent; inference can be added later.
- **R2:** a destination on the attacker's own side is not attacked (orbit as today).
- **R3:** a committed attack phase ignores fighters and the generic floor, owns its pull-out, and keeps the overspeed guard and a hard backstop. Defensive fire is E3.
- **R5:** kamikaze delivers the airplane's own bomb at point-blank range and ends in the sea beside the hull; there is no aircraft-into-ship collision rule in the sim, and adding one (a loop.ts and combat.ts change outside this item) is left open.
- **R4:** after its stores are gone an attacker flies off on its heading (no automatic return to base unless the pilot already has a `home`, whose existing fuel and damage rules apply).

## Out of scope

Formation level bombing and defensive gunners (E3). Tuning M2. Changing Convoy Strike or Airfield Strike. Ship-launched torpedoes (M4).
